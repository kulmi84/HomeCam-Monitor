HomeCam Monitor V2 – Windows-Verknüpfungssymbol ändern

Die lokale Desktop-EXE enthält drei auswählbare Symbole:
  1. Weiß auf schwarzem Hintergrund (Standard)
  2. Weiß auf transparentem Hintergrund
  3. Schwarz auf transparentem Hintergrund

Rechtsklick auf die Desktopverknüpfung → Eigenschaften → Verknüpfung
→ Anderes Symbol … → HomeCamMonitor-V2-Beta.exe als Datei auswählen.
Die drei Varianten erscheinen direkt in der Liste. Gewünschtes Symbol anklicken,
mit OK bestätigen und Übernehmen wählen.

Falls dort noch eine ICO-Datei eingetragen ist: Über Durchsuchen … die EXE
im Programmverzeichnis auswählen. Die drei ICO-Dateien liegen zusätzlich daneben.

Bei der Microsoft-Store-Ausgabe setzt die laufende App transparente Fenster-
und Taskleistensymbole passend zum Windows-Modus: Weiß bei dunkler, Schwarz
bei heller Taskleiste. Der Systemmodus wird jede Sekunde geprüft. Dafür ist
keine Auswahl in der App nötig. Die Store-EXE hat ein transparentes weißes
Standardsymbol; zusätzlich enthält das Paket beide transparenten Farbvarianten.

Die oben beschriebene manuelle Auswahl betrifft Windows-Verknüpfungen.
Bei geschlossener Store-App bestimmt Windows das Symbol der Anheftung.
In den App-Einstellungen gibt es keine Logo-/Iconanpassung.
