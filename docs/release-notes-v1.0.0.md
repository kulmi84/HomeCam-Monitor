# HomeCam Monitor V1.0.0

Kostenloser IP-Kamera-Monitor und RTSP-Player für Windows mit optionaler Home-Assistant-Integration.

V1.0.0 enthält den festgelegten Beta-22-Funktionsumfang: Einzelkamera oder 4-Kamera-Ansicht, Snapshots, Videoaufnahmen mit Vorlauf, automatische Wiederverbindung, Bewegungs-/Personensensoren über Home Assistant sowie Sicherung und Wiederherstellung der Einstellungen.

Das ursprüngliche HomeCam-Icon bleibt erhalten. Der Installer erkennt bestehende Beta-Installationen und aktualisiert das Programm; Einstellungen, Kameras und eigene Dateien bleiben erhalten.

## Downloads

- **HomeCamMonitor-v1.0.0-Setup.exe** – empfohlene Installation oder Aktualisierung unter Windows x64.
- **HomeCamMonitor-v1.0.0-win-x64.zip** – portable Version ohne Installer.
- **HomeCam-Media-corresponding-source.tar.zst** – korrespondierende Quellen der mitgelieferten mpv-/FFmpeg-Fremdprogramme einschließlich Dependencies und Buildrezepten. Für die normale Installation nicht erforderlich.
- **source-inventory.json**, **sources-manifest.json** und **SHA256SUMS.txt** – Versions-, Quellen- und Prüfsummennachweise.
- **HomeCamMonitor-v1.0.0-DEFENDER-SCAN.txt** – Ergebnis der automatischen Defender-Prüfung.
